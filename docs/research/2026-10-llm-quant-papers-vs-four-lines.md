### 2.1 arXiv 2604.26747：约束型 LLM 因子挖掘（加密）

**框架**（§3–§4）：
- LLM 只负责提出"可证伪假设 + 理由 + 候选类型 + DSL 配方"，由确定性引擎计算因子、执行门槛、做追加记录（§4.1）。

### 2.2 arXiv 2610.29500：LLM alpha 挖掘审计

这是一份案例审计（A 股、40 只股票、2024–2025），对象是一个"三角色流水线 + 20 专家蜂群"项目。作者明确说**不提出新方法**（§1）。发现如下：

1. **统计口径不一致（§4.2）**。流水线的"平均 Sharpe"是对 67 个已保留候选求均值（2.227），蜂群的"平均 Sharpe"是对 20 个"每轮最大值"求均值（2.433）。两者被当成同一个指标比较。分母也不同：234 是"成功评估数"，816 是"返回结果数"（含失败和翻符号重评）。
2. **配置和状态的来历不可追溯（§3、§4.3）**。门槛"Sharpe≥2、Fitness≥0、Turnover≤500"只是叙述；各工作流其实另有 IC、复杂度、相关性检查，**实际执行的版本没有和报告绑定**。两个系统比较时也没有快照或重置初始因子池。
3. **只保留正结果（§5，Table 2）**。1,837 条"样本外验证集"实际上在写入前就**剔除了样本外 Sharpe ≤ 0 的记录**：checkpoint 有 2,016 条，其中 368 条为负，这 368 条恰好全是"只出现在 checkpoint 中"的那些。所以"零符号反转率"是筛选造成的，不是因子泛化的证据。而且 1,837 条里只有 1,037 条满足它自己声明的样本内规则。
4. **全量重评（§6，Table 3）**：
   - 1,047 条冻结表达式全部保留编号重评，**没有任何一条按新分数挑选**。
   - 结果：923 条可评分，99 条有效日期不足，25 条算子不支持。不可评分的也留在分母里，**缺失不按 0 alpha 处理**。
   - 评估器 bug 修正做成新版本（v1 留档），并且**全量重跑，不是只重跑有希望的失败项**。
5. **未经训练的简单基线也是正的（§6.1，Table 4）**。成交量 rank-IC 为 +0.0234，20 日动量为 +0.0229，而因子群的中位数只有 +0.0148。结论："正 IC 本身不能证明 agent 有增量能力。"
6. **重叠的 5 日标签不是独立观测**，作者因此**拒绝对整体分布做显著性检验**（§6 末段）。

**一次干净样本外评估的配方**（§5 末段，原文逐条）：
- 恢复并哈希完整的样本外前候选池；
- 预先指定只用样本内数据的筛选规则；
- 去重只用样本内数据；
- 访问样本外之前冻结表达式列表；
- 每个响应都做 checkpoint；
- 不论符号，保留每一个样本外数值结果和错误。

→ 这份配方加上 §7 的三条原则（明确的指标粒度、不可变的全体账目、带来历的解读），就是 §4 自查清单的来源。

### 2.3 arXiv 2608.02985：LLM 回测的时间泄露

**核心定理**（§3，Theorem 2）：只看回测分数（预测、结果、难度、距截止日），**泄露膨胀 B 不可识别**。识别集是 `[0, E[1−m | G<0]]`，样本再多也不会收窄。原因是"模型对临近截止日的时期天然知道更多"（recency，正当知识）和"记住了结果"（leakage）由同一个截止日驱动。

- **推论**：朴素的截止前/后对比检查没有信息量。论文 Figure 1 中，5 个旗舰模型只用截止后才 resolve 的问题打分，按理不可能泄露，却有 4 个被朴素检查"判出泄露"（Δ=+0.044 ~ +0.061）。
- 反过来也成立：**截止前后表现平坦，也不能证明回测是干净的**（§3 末段）。

**泄露集中在哪里**（§4，Proposition 3）：
- 每题的泄露 = 诚实不确定性 b₀ × 提取系数 w(2−w)。只提取一半信号（w=0.5），就已经拿到完全记忆时 75% 的膨胀。
- 泄露集中在"出乎人群意料、且训练语料覆盖密集"的结果上。所以"平均污染率"是错误的审计对象。

**三条识别路线**（§5，Table 1）：

| 路线 | 输入 | 识别出什么 | 检查方法 |
|---|---|---|---|
| R1 已知截止日 → RD（断点回归） | 截止日 | 截止处的跳跃 J；外推后可得全局 B | 安慰剂断点、带宽、日期敏感性 |
| R2 干净对照模型 → DiD | 一个截止日早于评估窗、recency 画像匹配的模型 | 全局 B | 安慰剂截止日、协变量平衡。**对照太弱会高估 B**（GPT-3.5 对照把估计重新抬到 +0.055，§7.2） |
| R3 改写探针 → PRC | 多种改写问法 | 只能检测，不能估计 | 需要校准；完全记忆时失效 |

**落地流程**（附录 C.1 / Figure 6）：
- 第 5 步："**能等到截止后的结果时，优先做前向评估，此时 B=0 是构造保证的**"；
- 截止日不确定时，报告对截止日位置的敏感性；
- null 结果必须带上检出力下限（§6.2 "A null bounds; it does not certify"）。

验证与部署：
- 在 Qwen3.5 的 LoRA 孪生模型里植入已知剂量的泄露，估计量能还原剂量、位置和逐题分布（§6.1）；
- 在野外检出 GPT-5.5 截止日处的跳跃（§7.3）；
- 在 LiveCodeBench 上作为阳性对照（§7.4）；
- 代码：github.com/ZeyuZhang1901/Temporal-Leakage-Backtesting。

### 2.4 arXiv 2607.18867：HindsightBench

这是一个黑盒行为审计协议，载体任务是"给定某月宏观快照，生成 8 条带方向判断的假设"（§3.1）。

- **四臂日期操纵**：R 揭示日期 / D 只给日期 / M 掩去日期并清洗可识别上下文 / W 把真实数据贴上平移 66 个月的假日期。
- **两类探针**：REC 让模型给掩码快照定年；LAP 只给日期，追问真实结果，20 次采样（§3.2）。
- **六个指标，各带可识别性门槛**（§3.3）：E2 日期触发、E3 移植效应、P1 截止后安慰剂、REC、有效截止日、δ 解离系数。

与我们相关的发现：
1. **后见之明不一定是"查到结果"，也可能是"对那个时期的语义记忆"**（摘要、§5.1）。只要提示里带日期，模型就会套用那个时期的叙事；W 臂里叙事会跟着假日期走（E3 最高 +49.5pp）。2026 代的模型 6/6 都有这种触发反射，2024 代开源模型 0/3（§5.1）。
2. **行为上的有效截止日普遍早于厂商公布的日期**，最多早 8 个月（GPT-5.5 实测 2025-06，官方 2025-12；§6）。所以按日历画的"截止后安全窗"不可靠，必须相对模型自身来定。
3. **审计结果受服务细节影响**：量化精度、thinking 模式、解析器版本、是否开启检索都会改变结果（§7.1–7.3）。协议因此要求把这些设置写死并披露。
4. **工程纪律**：
   - 预登记做 SHA-256 冻结（§3 "frozen (SHA-256 fbcdffc1) before any non-development model was called"）；
   - 冻结后的修正一律做成新版本、全量重新生成并披露；
   - 记录从不删除，被取代的标记原因后保留（§8 "Rows are never deleted"）；
   - 表格由脚本从冻结的行文件生成，带 `--check` 漂移门禁（§4）。

### 2.5 arXiv 2608.31041：Agentic 量化交易综述（只看 §4–§6）

- **Finding 3**（§5）：在所有报告了交易结果的实盘基准里，实际表现都取决于模型能力以外的因素，包括风控、系统设计、流动性和滑点。三个可靠性基准（FinLake-Bench、AutoRedTrader、KTD-FIN）都显示，泄露、错误信息或收益归因会改变对 agent 表现的解读。"回测成功或预测准确，是比实盘或可靠性评估更弱的证据。"
- **Table 2 Panel D**：
  - Profit Mirage / FinLake-Bench：截止日之后回测收益下降，反事实测试暴露出对已记住结果的依赖；
  - HindsightBench §2 引用：截止日后 Sharpe 衰减 51–62%；
  - KTD-FIN：掩码会改变 agent 的决策，而收益主要来自市场和风格暴露，不是选股。
- **§6**："评估要与能力主张匹配。可执行的策略不等于能盈利，能盈利的回测也不等于有实盘能力。"

### 2.6 arXiv 2606.04574：加密多币对配对交易 + DRL

**设置**：
- 数据：Binance USD-M 1h；IS 为 2024 年，OOS 为 2025 年（§3.2）。
- 每月按前 2 个月的成交量取流动性前 100 个币；在 4,950 个组合里选前 20 对，用 Hurst<0.5、β>0 做硬过滤（§3.5）。
- 成本：单边 5bp，压力测试 10bp（§3.4）。
- **所有主结果都在 10x 杠杆下**（Table 15/16 注）。

问题点：
- **种子挑选**：Table 14 中 5 个种子的 OOS CAGR 分别是 33.46%/48.69%/**199.45%**/−3.00%/43.20%，均值 64.36%、标准差 69.91%。§6.5.5 显著性检验用的正是 seed 42 的 199.45%。即便如此，Sharpe 差值的 p 值也只有 0.0603，95% 区间为 [−0.43, 11.37]，**跨过了 0**。
- **"240 个独立 pair-month episode"**（§3.2）把同月共振的配对当作独立样本，正是我们"跨币共振日聚类"踩过的坑。
- **模型选择**（§6.2）：在 IS 上，先按持仓时长与基线对齐过滤，再取胜率最高者，**而且选择时关闭了风控 overlay，OOS 时再打开**。这样选择时和部署时不是同一个系统。

## 5. 本文最重要的一节：我们自己的 LLM 后见之明问题

**事实**：
1. 四条线的假设几乎全部由 Claude 提出（git trailer：Opus 4.5/4.6 → Fable 5 → Opus 5/5.5）。本文作者（Opus 5.5）自述的知识截止是 2026-06。
2. 冻结缓存止于 2026-04-09。也就是说，A 段（2021-02~2024-06）、B 段（2024-07~2026-04）、史前段（2017–2020）**全部落在近期生成模型可能见过的时期内**。HindsightBench §6 显示，有效截止日最多比官方日期早 8 个月，所以不要试图靠"早期模型截止日较早"来给某些假设开脱，这些截止日本身就不可靠。

**从论文迁移过来的结论**：
- **我们的 LLM 提出的是规则，不是逐日预测**，所以 2608.02985 的 RD/DiD 估计量不能原样照搬：它需要逐题的概率预测和 resolve 日期。能迁移的是三条原理：
  1. **不可识别性**（2608 Theorem 2）。"2025+ 全线 alpha 衰减"（VALIDATION.md 矛盾本质段、各线共同观察）在逻辑上至少有三种解释：①结构真的死了（regime change）；②LLM 带着对 2021–2024 行情的记忆提出了恰好适配那段时期的规则（evidence leakage，w∈(0,1)）；③普通的多重检验回归均值。**只看历史回测，三者分不开**。Profit Mirage 报告的"截止后 Sharpe 衰减 51–62%"（HindsightBench §2 引用）在形态上和我们观察到的衰减一模一样。
  2. **泄露集中在"出乎意料且语料覆盖密集"的事件上**（2608 §4）。加密行情里最被大量报道的恰恰是极端事件：2021 牛市、2022 LUNA/FTX、2024 ETF、2025 关税冲击、2026 熊市段。而 combo2 的 edge"全在右尾"（research_from_zero/README R2）。右尾事件正好也是最可能被记住的事件。**这不等于证明 combo2 被污染**：M+ 的规则是机械的 2σ 放量，且史前 2017–2020 通过。但"史前通过"同样落在训练语料覆盖期内，不能当作泄露对照。
  3. **前向评估 B=0**（2608 附录 C.1 第 5 步）。dry-run 是全体系里**唯一在构造上不受 LLM 泄露影响的证据**。这给"dry-run 裁决才是最终法庭"补上了一条此前没有写下的理由。前提是被裁决的规则在 dry-run 期开始之前就已冻结。combo2 满足（配置 2026-07-15 冻结，VALIDATION ⑦②）。
- **HindsightBench 的启示**：只要提示里带日期或时期，模型就会调用那个时期的叙事（E2/E3）。我们给探索 agent 的提示通常会写"2025 年后 alpha 衰减"、"2026 熊市段"这类时期描述，C 线 R19 的"污染声明"就是一个被自己发现的实例（LEDGER.md:81）。这类提示会把"对时期的记忆"直接注入假设生成。

**B 段对 LLM 生成的假设算什么**：它仍然能防普通过拟合，因为规则在 A 段写死后才看 B，这一层防护依然有效。但它**不再是对 LLM 泄露的干净对照**。正确的叫法是"半样本外"：对过拟合是样本外，对生成者的记忆是样本内。

### R2. 预登记改为"两段式提交 + 内容哈希"，并修补 quant-top10 的 holdout 守卫

- **改哪里**：

- **预期收益**：把"先登记后看"从惯例变成可以审计的事实（§3 第 5 行四条线全部是"没有"或"部分"）。顺带防止 C 线 holdout 被静默二次读取。
- **会不会破坏已有裁决**：不会。只对新假设生效。**C 线补丁不能让历史 gate 重跑**：补丁上线后，已燃烧的族在重跑时会被拒绝，这正是想要的效果。

### R3. 把 B 段对 LLM 生成假设降级为"半样本外"，并把前向评估写进各线的验证纪律

- **改哪里**：
  - 在各线的纪律文档（`BC/strategies/combo2/VALIDATION.md` 方法论附注、`BC/quant-zero/README.md`、`QT/README.md`、`EL/README.md`）各加一段，统一措辞："B 段 / 史前段对 LLM 生成的假设是半样本外（对过拟合是样本外，对生成者记忆是样本内）；唯一 B=0 的证据是在规则冻结之后、并晚于生成模型训练截止日的前向数据，也就是 dry-run 或纸面。"
  - 探索提示词规范：给探索 agent 的提示**不写具体时期的行情叙事**，比如"2025 年后衰减"、"2026 熊市"（HindsightBench E2/E3）。时期只用 A/B 这样的标签表示。
  - **可选诊断，不作裁决用**：把 LLM 生成的存活规则，与一组"生成时间早于数据"的文献固定规则做 DiD 式对照，看两组在 2025+ 的衰减幅度是否有差异（2608 §5.2 的思路）。文献固定规则例如 TSMOM 时序动量、Liu-Tsyvinski 动量，规则在 2021 年前就已经发表。只有 LLM 组衰减明显更多，才构成泄露足迹。注意 2608 §5.2 的警告：**对照组的 recency 画像必须匹配，对照太弱会高估泄露**。这项诊断要在 B 段上跑文献规则，文献规则不属于我们的假设，不消耗我们任何假设的 B 段配额。但如果引用我们存活规则的 B 段结果，只能用账本里已有的那一次结果，**不得重跑**。
- **成本**：文档约 1 小时，零代码；DiD 诊断约 1 天，可选。
- **预期收益**：给"2025+ alpha 衰减"增加一个此前没被考虑的解释通道。更重要的是防止将来出现"B 段通过就当真"的误判。让 dry-run 的地位有了理论依据（2608 附录 C.1）。
- **会不会破坏已有裁决**：不会。combo2 在 2026-12-17 的生死线和通过线一字不动；这只是改变对 B 段证据的"权重解读"，不改变任何已登记的阈值。

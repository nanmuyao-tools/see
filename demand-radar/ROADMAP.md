## 定位

开源、自托管的需求发现工具。同类项目（Reddit_Scrapper、pain-miner、sift 等）都在早期，没有一个同时做到：**全本地模型、一条命令部署、质量可量化**。这三点是我们的差异化，后续每一步都不能丢：不引入必须付费的 API，不增加部署步骤，每次改动都过评测。

市场调研的结论是需求真实、商业天花板有限，所以**先做出能发布的版本拿到真实反馈，再做重功能**。

## 现在在哪

v0.1 功能已全部完成：四类公开数据源 → 规则预过滤 → 本地模型抽取 → 有害规则标记 → MongoDB → 排序 → 清单 / 周报（中英文），`docker compose up` 一条命令部署，72 个离线测试，CI 通过。已在 Mac（M5）上真机跑通。

质量：61 条标注样本（46 条真实 + 15 条构造），qwen2.5:3b、温度 0：

| 输出语言 | F1 | 精确率 | 召回率 | 有害需求进清单 | 正常需求被转人工 | 规则误杀 | 61 条耗时（沙箱 CPU） |
|---|---|---|---|---|---|---|---|
| 中文 | 83.6% | 92.0% | 76.7% | 0 | 0 | 0 | 709 秒 |
| 英文 | **89.7%** | 92.9% | 86.7% | 0 | 0 | 0 | 591 秒 |

中文比验收线（85.1%）低 1.5 个百分点，差在 1 条样本上（基线是在旧的 45 条上测的）。在 60 来条样本上 1–2 条的差别分不清是改进还是噪声，下一步先把评测集扩到 100 条以上，再做细调。

## 里程碑

### v0.1：可以发布（约 1.5 周）

拿得出手，能放到社区让人试用，并能每周产出有价值的内容。

- [x] 规则预过滤：空帖、作品发布帖、机器人内容等不再交给模型（评测集里挡掉 10 条，零误杀）
- [x] 分项打分：痛点清晰度、表达强度、可实现性
- [x] 原文摘录：程序从原帖挑一句最像需求的原话（模型抄写时约 29% 被翻译或改写，改由程序挑）
- [x] 输出语言可配置：中文 / 英文，两种语言各一份完整提示词
- [x] 抽取失败也记录，超过 3 次不再重试
- [x] 综合排序：分项打分 + 热度
- [x] 每周摘要命令 `digest`
- [x] 有害需求（追踪、监视、曝光、骚扰、欺骗特定的人）不进正文，转「待人工确认」区
- [x] 默认模型 3b；MIT 协议；英文 README；CI
- [x] `local/<模型>`：接任意 OpenAI 兼容的本地服务（mlx-lm、LM Studio、llama.cpp）
- [ ] 拆成独立仓库（等你定名字）

验收：评测 F1 ≥ 85.1%（英文 89.7% ✓，中文 83.6% ✗ 差 1 条），摘录全部是原文原话 ✓，规则零误杀 ✓，有害需求进清单 0 条 ✓；Mac 上 `docker compose up` 能出清单和摘要 ✓。

**发布后**：发到 HN、r/SaaS、Indie Hackers、V2EX，收集反馈，再决定 v0.2 的优先级。

### v0.2：持续积累（约 1.5 周）

跑一个月后，库里是几千条有效需求，而不是每天重复处理同样的内容。

- [ ] 评测集扩到 100 条以上（中文 F1 离验收线只差 1 条，样本太少分不清改进和噪声）
- [ ] 增量抓取：每个源记录上次抓到哪
- [ ] 历史回填：softwarerecs 有 2.3 万条、HN 关键词能命中上万条，分批拉，可中断续跑
- [ ] 并发调用模型
- [ ] 运行记录：每次运行的抓取数、过滤数、失败数、耗时
- [ ] 定时运行：每天抓取，每周出摘要
- [ ] 实测 Arctic Shift 作为 Reddit 数据源（可能同时解决限流和历史数据问题）

验收：连续运行一周不重复处理；回填能中断续跑。

### v0.3：合并与看板（约 2 周）

- [ ] 相似需求合并：本地 embedding 模型向量化，先用相似度阈值，不够再上 UMAP + HDBSCAN
- [ ] Web 看板：FastAPI + 静态页，按领域、时间、排序分筛选
- [ ] 「已有方案」提示：优先评估集成现有的 idea-validation 开源项目

验收：同一需求在多个来源出现只显示一条，标明来源数和总热度。

## 模型选择

测试阶段默认 **qwen2.5:3b**。纯 CPU 沙箱、45 条评测的对比：

| 模型 | 45 条耗时 | F1 | 结论 |
|---|---|---|---|
| qwen2.5:3b | 390 秒 | 85.1% | 默认 |
| qwen2.5:1.5b | 198 秒 | 78.0% | 低配机器备选 |
| qwen2.5:0.5b | 103 秒 | 0% | 不可用 |
| qwen3:1.7b | 每条 30 多秒 | — | 默认开启思考模式，比 3b 还慢，不推荐 |
| llama3.2:1b、gemma3:1b | 未测完 | — | 中文弱，优先级低 |

上表是 45 条时的数据。v0.1 的 61 条结果见「现在在哪」。

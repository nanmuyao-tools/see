# 需求雷达：市场调研与潜力分析

调研时间：2026-10-19。数据多来自第三方评测、厂商博客和公开快照，**不少数字彼此矛盾，只能看量级和趋势，不能当精确值**。每条数据都标了出处，可信度低的单独注明。同类开源项目的对比见 [`landscape.md`](landscape.md)。

## 一、结论先说

- **需求真实存在**：这个方向最知名的商业产品 GummySearch 有十多万注册用户；找点子类工具有人付费，月费几十到几百美元。
- **但商业天花板不高，平台风险很大**：GummySearch 收入最乐观的估计也只有月入约 3.5 万美元，最后因为拿不到 Reddit 的商业数据授权而关停。
- **趋势是顺风**：AI 写代码让「做出来」越来越便宜，独立开发者占比持续上升，「做什么」更重要了。但也有观点认为现在真正的瓶颈是获客，而不是找点子。
- **对你的目标来说，这是个合适的项目**：作为开源作品和个人工具，潜力不错；作为创业项目，潜力中等偏低，不建议现在就按商业产品来做。

## 二、需求证据

### GummySearch：这个市场最好的参照

GummySearch 帮用户在 Reddit 上找目标用户的痛点，是这个领域最知名的产品。

| 指标 | 数据 | 说明 |
|---|---|---|
| 注册用户 | 约 13.5–14 万 | 来自关停时的公开说明，可信度较高 |
| 付费用户 | 约 400 到约 1 万 | 两个来源差了 25 倍：GetLatka 估计巅峰时约 400 人；另一说法是关停时约 1 万人 |
| 收入 | 2023 年约 9.6 万美元；关停时月入约 3.5 万美元 | 同样来自不同来源，无法和原始数据核对 |
| 结局 | 2025-11-30 停止新注册，2026-12-01 全面关停 | 官方原因：Reddit 的数据 API 禁止商业使用，没谈下授权 |

来源：[GummySearch 关停说明](https://gummysearch.com/docs/gummysearch-is-now-closed-6533h)、[ParseStream 评测](https://parsestream.com/gummysearch-review)

**怎么解读**：
1. 十多万人注册，说明「从社区找痛点」是很多人想要的。
2. 付费转化很低（最多不到 10%），收入规模也有限。最乐观地算，年收入也就 40 万美元左右，属于小而美的独立产品量级。
3. **最大的风险不是没人要，而是数据源被平台卡住。**

### 同类付费产品的定价

| 产品 | 定位 | 价格 |
|---|---|---|
| Exploding Topics | 趋势发现 | $39 / $99 / $249 每月 |
| IdeaBrowser | 点子库 + 验证工具 | 约 $1,499 每年（不同来源有 $499–2,999 不等的说法） |
| Reddinbox | Reddit 痛点和情绪分析 | $39–99 每月 |

来源：[Exploding Topics 定价](https://marketintelligencetools.com/reports/exploding-topics-pricing/)、[IdeaBrowser 对比](https://preuve.ai/compare/alternatives-to/ideabrowser)、[GummySearch 替代品对比](https://simular.ai/alternatives/gummy-search-alternatives)

**怎么解读**：「帮我找到该做什么」这件事，有人愿意每月花几十美元。

### GummySearch 关停后的空缺

关停之后出现了大量「GummySearch 替代品」的对比文章和新产品，还有开发者写文章介绍自己用笔记本上的 4B 小模型复刻了 GummySearch 的每日流程（[DEV 社区文章](https://dev.to/prateek11rai/gummysearch-deletes-everyones-data-on-december-1-i-rebuilt-its-morning-loop-on-a-4b-model-on-my-71i)）。这说明 GummySearch 的用户在找替代品，也说明「本地跑小模型」这条路有人在走，和我们的方向一致。

## 四、趋势

**顺风：做软件越来越便宜。** 有厂商估计用 AI 编程做出 MVP 的成本是传统方式的 1/50 到 1/100（[Questera](https://www.questera.ai/blogs/vibe-coding-statistics-2026)，厂商数据，仅供参考）；IDC 也指出长期以来「写代码」这个瓶颈正在被改变（[IDC](https://www.idc.com/?p=108586)）。做出来不难了，「做什么」的价值就更突出。

**逆风一：真正的瓶颈可能是获客。** 同一篇文章认为，很多创业者发现发布得更快并不等于赚钱更快，常常卡在月入 0–2000 美元。如果这个判断对，那么「找点子」只是解决了前半段问题。

**逆风二：通用 AI 也能干这件事。** ChatGPT、Perplexity 的深度研究功能可以临时去搜 Reddit 上的抱怨（[Axios 测评](https://www.axios.com/2025/02/07/chatgpt-deep-research-gemini-review)）。但它们是一次性的、每月有次数限制、结论会出错，不能持续积累和去重。我们的价值要体现在**持续、可积累、质量可量化**上，而不是「能搜一次」。

## 五、我们的位置

| 维度 | 机会 | 风险 |
|---|---|---|
| 数据源 | 用户在自己电脑上运行，各自访问公开接口；数据源不止 Reddit | Reddit 等平台随时可能收紧；用户本人仍需遵守各平台条款 |
| 本地模型 | 不需要 API key，没有使用成本，数据不出本机，正好对上 GummySearch 关停后「自己掌握」的需求 | 本地模型质量和速度不如云端大模型 |
| 部署 | `docker compose up` 一条命令，门槛比同类开源项目低 | 目标用户里有不少人不愿意折腾 Docker |
| 质量 | 有评测集，F1 可量化 | 评测集只有 45 条，还要继续扩充 |
| 竞争 | 开源同类项目都很小，没有领头者 | 也可能说明这类工具的吸引力天然有限 |

**关于平台风险的一点说明**：GummySearch 的问题是它作为一家公司，把 Reddit 的数据加工后卖给付费用户。我们是开源工具，由用户自己运行、自己访问公开接口，模式不同。但这不等于没有风险：用户仍要遵守各平台的条款。**如果以后要做托管版或收费服务，就会遇到和 GummySearch 一样的授权问题。**这一点不是法律意见，真要商业化需要专门确认。

## 六、潜力评估

| 作为…… | 潜力 | 理由 |
|---|---|---|
| **开源项目** | **中等偏上** | 有真实需求，同类项目都没做好，我们有明确差异化。执行和推广得好，几百到一两千星是现实的目标（参照：同类最大的 Reddit_Scrapper 是 214★）。这是估计，不是承诺 |
| **个人工具** | **高** | 你自己就是目标用户：它直接回答「我下一个项目做什么」 |
| **作品集** | **高** | 覆盖数据抓取、本地大模型、评测体系、Docker 部署，是一个完整的工程作品 |
| **商业产品** | **中等偏低** | 市场天花板有限、付费转化低、平台风险高；托管版会遇到数据授权问题 |

## 七、可能的变现方式（如果以后想做）

按风险从低到高：
1. **公开的每周需求报告**：用工具生成，做成博客或订阅邮件。不卖数据，只卖整理和判断。同时也是项目最好的宣传。
2. **开源 + 赞助**：GitHub Sponsors 等。
3. **付费增强功能**：比如更好的聚类、看板、提醒，但核心保持开源。
4. **托管版**：门槛最低、用户最多，但会遇到数据授权问题，**不建议**。

## 八、建议

1. **定位**：开源、自托管的需求发现工具，主打「GummySearch 关了之后，自己掌握的替代方案」。这是一个现成的、有人在找的叙事。
2. **先验证，再加功能**：做出可用版本后，在 HN、r/SaaS、Indie Hackers、V2EX 发布，看真实反馈。可以给自己定一个检验标准，比如发布一个月内能不能拿到 100 颗星、有没有人主动提 issue。这个标准是建议，可以按你的情况调整。
3. **用每周报告做获客实验**：每周发一份「本周值得做的需求」，同时验证两件事：工具产出的清单有没有价值，以及有没有人愿意持续关注。
4. **暂不考虑商业化**：等开源版本有了用户、清单质量被认可之后再说。
5. **降低平台依赖**：继续扩充非 Reddit 的数据源（HN、StackExchange、GitHub issues 已经有了），不让任何一个平台成为单点。

## 待核实

- GummySearch 的真实付费人数和收入（几个来源差距很大）
- 中国独立开发者的规模，以及 V2EX、即刻等中文社区的可用数据源和条款
  - 2026-10-28 部分核实（见 [research/2026-10-28-data-sources.md](research/2026-10-28-data-sources.md)）：V2EX 的 JSON API 被 Cloudflare 挡住，节点 Atom feed 可读（「问与答」每周约 240 帖），robots 和条款页都 403，条款仍未拿到；知乎、小红书的 robots 对 `*` 都是 `Disallow: /`；即刻要登录。独立开发者规模仍无数据
- 各数据源平台对「用户自行运行的开源工具」的具体条款要求

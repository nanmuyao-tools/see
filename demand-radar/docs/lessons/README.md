# 教学：给 agent 做检索（RAG）

用需求雷达的真实数据，分两课讲「检索」这一层。两课的代码用同一个接口（`demand_radar/retriever.py`），
一行配置切换后端，结果应当完全一致（`tests/test_qdrant_parity.py` 保证）。

| 课 | 讲什么 | 要不要额外服务 |
|---|---|---|
| [第一课：暴力检索](01-brute-force.md) | 向量就是一串数，检索就是算余弦再排序；没有任何黑盒 | 不要（项目默认） |
| [第二课：向量库](02-vector-db.md) | HNSW 近似索引、过滤、什么数据量才需要它；用 Qdrant，并自己量出交叉点 | 要（可选的 Docker profile） |

先学第一课再学第二课：没摸过暴力检索，就看不出向量库到底省了什么。

**这两课不改变项目本身**：不装 Qdrant 时一切照旧（默认镜像、依赖、测试都不变），Qdrant 全部是可选的。
